# 権限設計

実装: `src/lib/auth/permissions.ts`。画面・Server Action の両方でこの定義を使ってサーバー側で検証する。

| 権限 | 内容 | 管理者 | IT資産管理担当者 | 一般社員 |
|---|---|:-:|:-:|:-:|
| `dashboard:view` | ダッシュボード | ○ | ○ | |
| `device:read` / `device:write` | 端末の閲覧 / 登録・編集 | ○ / ○ | ○ / ○ | |
| `employee:read` / `employee:write` | 社員の閲覧 / 登録・編集・退職処理 | ○ / ○ | ○ / | |
| `location:read` / `location:write` | 拠点の閲覧 / 登録・編集 | ○ / ○ | ○ / | |
| `master:write` | 部署・資産種別マスタの編集 | ○ | | |
| `assignment:write` | 貸出・返却 | ○ | ○ | |
| `move:write` | 拠点間移動 | ○ | ○ | |
| `maintenance:write` | 修理登録 | ○ | ○ | |
| `disposal:write` | 廃棄処理 | ○ | | |
| `device:secret` | 端末パスワードの表示・端末ログイン情報の変更 (表示は操作履歴に記録) | ○ | | |
| `csv:import` / `csv:export` | CSV インポート / エクスポート | ○ / ○ | ○ / ○ | |
| `audit:read` | 操作履歴の閲覧 | ○ | ○ | |
| `user:manage` | 利用者の登録・権限変更・無効化・パスワード再設定 | ○ | | |
| `settings:manage` | システム設定 | ○ | | |
| `self:read` | 自分の貸与端末・貸与履歴の閲覧、自分のパスワード変更 | ○ | ○ | ○ |

一般社員は `self:read` のみを持ち、閲覧できるのは自分の社員 ID に紐づく貸与情報だけ
(クエリに必ずログイン利用者の `employee_id` を条件として含める)。
将来の「貸出・返却申請」は一般社員向けの新しい権限として追加する。

## 利用者管理のルール

- 自分自身の権限変更・無効化はできない。有効な管理者が 0 人になる変更はできない
- 権限変更・無効化・パスワード再設定を行うと、その利用者のログイン中のセッションは無効になる
- 一般社員の利用者は社員情報との紐付けが必須 (1 人の社員に紐付けられる利用者は 1 人まで)
- 社員の退職処理を行うと、紐付いた利用者は自動で無効になる
